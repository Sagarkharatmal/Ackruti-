# Pothole Detection System (Mumbai)

> **Made by SSK** · Started 06 October 2026, 10:21 IST

This project is kept separate from the rest of this repository. Its goal is an AI system for Mumbai that:
1. detects potholes from phone or dashcam footage,
2. works out which agency owns each road, and which contractor and tender are responsible, by crawling public tender data,
3. checks whether the road is still under warranty (the defect liability period), and
4. produces and tracks complaint files until each pothole is fixed.

## Status
Research and design phase. No application code has been written yet.
